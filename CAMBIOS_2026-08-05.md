# MILLONARIO 2026 — paquete corregido para pruebas DEMO

Se conservaron las reglas y parámetros de entrada de las tres estrategias.
No se añadieron indicadores ni se optimizaron parámetros para mejorar resultados.

## Correcciones aplicadas

- El token y App ID del `.env` se conservaron por solicitud del propietario.
- La conexión está bloqueada en modo DEMO desde `api/deriv.py`.
- Los swings de estructura se publican únicamente después de su confirmación.
- La temporalidad superior sigue siendo 900 segundos (M15), pero ahora se crea
  realmente desde las velas menores cuando no existe un dataset M15.
- Las velas HTF solo se vuelven utilizables al cerrar.
- Se reparó la función pública `calculate_metrics` usada por métricas avanzadas.
- El dashboard toma riesgo, ATR, relación riesgo/beneficio y costos desde `config.py`.
- El circuit breaker de drawdown ya bloquea entradas nuevas en el motor del dashboard.
- La simulación en vivo admite BUY y SELL y continúa sin enviar órdenes reales.
- La tabla `live_trades` migra de forma compatible para guardar la dirección.

## Prueba rápida sin internet

```bash
python PRUEBAS_CORRECCIONES.py
```

## Dashboard

```bash
pip install -r requirements.txt
python app_web.py
```

Luego abre `http://127.0.0.1:5000`.

## Simulación demo

```bash
python live_simulation.py R_50 60
```

El script se conecta exclusivamente a una cuenta de tipo `demo`.
